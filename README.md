# Horizons Controller Support

This project is a browser extension designed to add or enhance controller support for hackclub horizons.

## Features
- Injects custom scripts into the game web interface
- Adds or improves controller/gamepad support

## Installation
1. Clone or download this repository.
2. Load the extension in your browser:
   - For Chrome/Edge: Go to `chrome://extensions/`, enable Developer Mode, and load the folder as an unpacked extension.
   - For Firefox: Go to `about:debugging`, click "Load Temporary Add-on" and select the `manifest.json` file.

## Usage
- Once installed, the extension will automatically activate on the relevant game web pages.
- Use your controller as you normally would; the extension will handle input mapping and enhancements.
